## Dispatch Pattern

- Commands are thin task entry points for common workflows.
- Agents own larger task behavior, such as generation, conversion, integration, or validation.
- Skills provide reusable procedural knowledge and deterministic helper scripts.
- When a task has both a command and a skill, the command is the user-facing shortcut and the skill is the reusable implementation guidance.
